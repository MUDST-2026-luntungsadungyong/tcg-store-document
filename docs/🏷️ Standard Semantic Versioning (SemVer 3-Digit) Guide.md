## 🧩 โครงสร้างตัวเลข 3 หลัก (SemVer Structure)

> **ตัวอย่างเลขเวอร์ชัน:** `v1.0.0`
> 

| หลัก | ตำแหน่ง / ชื่อหลัก | ความหมาย & การเปลี่ยนแปลง | ตัวอย่าง Frontend | ตัวอย่าง Backend |
| --- | --- | --- | --- | --- |
| **1** | **Major** | **Breaking Changes**<br/>การเปลี่ยนแปลงระดับโครงสร้างที่ส่งผลกระทบย้อนหลัง (ของเก่าใช้ไม่ได้ ต้องแก้โค้ดตาม) | รื้อแอปทำใหม่ทั้งหมด, ยกเลิกการรองรับ OS เวอร์ชันเก่า | เปลี่ยนโครงสร้าง Database ใหม่, ลบ API เก่าทิ้ง, เปลี่ยนโครงสร้าง JSON Response |
| **2** | **Minor** | **New Features**<br/>การเพิ่มฟีเจอร์ใหม่แบบ Backward Compatible (ของใหม่ใช้ได้ ของเก่ายังทำงานได้ปกติ) | เพิ่มหน้าจอ "โปรไฟล์ผู้ใช้", เพิ่มปุ่มแชร์ | สร้าง API Endpoint ใหม่ (เช่น `/api/v1/users/profile`) โดย API เดิมยังทำงานเหมือนเดิม |
| **3** | **Patch** | **Bug Fixes**<br/>การซ่อมแซมบัคหรืออุดช่องโหว่ความปลอดภัย โดยไม่มีการเพิ่มฟีเจอร์ใหม่ | แก้ปัญหาแอปค้างเวลากดปุ่ม, ปรับแก้ตัวหนังสือที่สะกดผิด | แก้บัคคำนวณเงินผิด, อุดช่องโหว่ความปลอดภัย (Security Patch) |

> ⚠️ **กฎเหล็ก (Reset Rule):**
> 
> 
> หากขยับเลขหลักที่ใหญ่กว่า (ขยับตัวเลขทางซ้าย) **เลขทางขวามือทั้งหมดจะต้องถูกรีเซ็ตเป็น 0 เสมอ**
>
